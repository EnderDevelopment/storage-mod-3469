# Storage Mod

Enhance your Minecraft storage with this versatile mod

## Features

- Adds a custom storage block to Minecraft
- Provides a basic GUI for item storage

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.11 or later
- Fabric API

## Installation

1. Download the mod JAR file
2. Place it in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

1. Craft or obtain the Storage Block
2. Place it in your world
3. Right-click the block to open the storage GUI

## Configuration

The mod does not have a configuration file. All settings are hardcoded in the source code.
